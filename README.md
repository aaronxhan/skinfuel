# Skinfuel website (Vercel)
Static HTML/CSS/JS, no build step. Pages: index, shop, routine, story, faq, policies.
Deploy: upload this folder to a GitHub repo, import in Vercel, framework preset "Other".

## Edit before launch: assets/js/config.js
shopUrl (TikTok Shop), cleanserUrl / moisturizerUrl (optional), instagramUrl, contactEmail, signupUrl (Brevo/Mailchimp/Formspree endpoint; blank = demo, nothing stored). Blank Instagram/email links hide automatically.
